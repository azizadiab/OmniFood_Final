# Omnifood Project 🍽️

A modern and responsive landing page for a fictional AI-based food subscription service.

## 🚀 Live Demo
https://omnifood2026.netlify.app/

## 📌 Project Overview
Omnifood is a front-end project focused on building a clean, modern, and fully responsive website using HTML, CSS, and JavaScript, C#, ASP.NET, Sql fundamentals.

The project emphasizes:
- Semantic HTML
- Modern CSS layouts
- Responsive design principles
- Basic JavaScript interactions
- User Registration
- User Login
- Subscription Plan Selection
- RESTful API Integration
- Online Deployment

## 🛠️ Technologies Used
## Frontend:
- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (ES6)
- Google Fonts
- Fetch API

## Backend
- ASP.NET Core 8 Web API
- C#
- ADO.NET
- SQL Server
- Stored Procedures
- Transactions
- Layered Architecture (Presentation, Business, Data Access)

## Deployment
- Netlify (Frontend Hosting)
- MonsterASP.NET (Backend Hosting)
- SQL Server Database Hosting

## Frontend Features 
- Fully responsive layout
- Clean and modern UI
- Smooth scrolling navigation
- Optimized images for performance
- Cross-browser compatibility

## Backend Features
- User Registration API
- User Authentication API
- Email Uniqueness Validation
- Database Transactions for Data Consistency
- SQL Stored Procedures
- CORS Configuration
- HTTPS API Communication

## 📱 Responsive Design
The website is optimized for:
- Desktop

- Mobile devices
